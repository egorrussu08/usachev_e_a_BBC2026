## Домашняя работа № 1. Калькуляторы

**Цель:** освоить ввод и вывод данных, арифметические операции, условные конструкции, функции и использование модуля `math`.

### 1. Простой калькулятор — файл `1.py`

Программа считывает два целых числа и знак операции, затем выводит результат. Поддерживаются сложение, вычитание, умножение и целочисленное деление через оператор `//`. Каждая операция проверяется отдельным условием `if`.

**Использованные средства:** `input()`, `int()`, `print()`, условные конструкции и арифметические операторы.

### 2. Калькулятор с циклом и одной функцией — файл `2.py`

Вычисление вынесено в функцию `f1(x, y, z)`, где `z` — знак операции. Ввод выполняется внутри цикла `while True`, поэтому после одного вычисления программа сразу переходит к следующему. Отдельной команды выхода нет.

**Использованные средства:** объявление функции, бесконечный цикл, ветвление `if` / `elif`.

### 3. Калькулятор с отдельными функциями — файл `3.py`

Каждая операция оформлена как отдельная функция, которая возвращает результат:

| Функция | Назначение |
| --- | --- |
| `summ(x, y)` | Сложение |
| `raz(x, y)` | Вычитание |
| `pr(x, y)` | Умножение |
| `dell(x, y)` | Целочисленное деление |

Сначала вводится знак операции, затем два целых числа. Программа выбирает нужную функцию и выводит возвращённое значение.

**Использованные средства:** несколько функций с `return`, выбор действия по условию.

### 4. Расширенный математический калькулятор — файл `4.py`

Функция `calc()` поддерживает и обычные арифметические операции, и функции из модуля `math`.

| Команда | Действие |
| --- | --- |
| `+`, `-`, `*` | Сложение, вычитание и умножение |
| `/` | Целочисленное деление |
| `sqrt` | Квадратный корень |
| `sin`, `cos`, `tan` | Тригонометрические функции |
| `log` | Натуральный логарифм |

Для тригонометрических функций угол вводится в градусах и переводится в радианы через `math.radians()`. Реализованы проверки деления на ноль, отрицательного аргумента квадратного корня, неположительного аргумента логарифма и неизвестной команды.

**Результат работы:** четыре версии калькулятора — от последовательных условий до программы с функциями, циклом и модулем `math`.

## Домашняя работа № 2. Тренажёр методов строк

**Цель:** изучить методы строк Python и закрепить их на практике через выбор уровня и операции.

Программа работает в цикле `while True`. Пользователь вводит номер уровня, читает пояснение, затем применяет выбранный метод к своей строке.

### Уровень 1. Изменение регистра

- `upper()` переводит строку в верхний регистр;
- `lower()` переводит строку в нижний регистр;
- `capitalize()` делает первую букву заглавной, а остальные — строчными.

Перед выполнением программа объясняет разницу между методами на примере строки «пРиВет - МИР».

### Уровень 2. Поиск, замена и подсчёт

Пользователь выбирает действие по номеру:

| Номер | Метод | Действие |
| --- | --- | --- |
| `1` | `find()` | Возвращает позицию первого вхождения подстроки или `-1`, если она не найдена |
| `2` | `replace()` | Заменяет указанную подстроку новой |
| `3` | `count()` | Подсчитывает количество вхождений |

В пояснении также разобран метод `index()`, который при отсутствии подстроки вызывает ошибку. В текущей версии программы этот метод только объясняется, отдельного пункта меню для него нет.

### Уровень 3. Разделение и объединение строк

- `split()` разбивает строку по выбранному разделителю и выводит список частей;
- связка `split` + `join` собирает символы строки заново с новым разделителем.

### Уровень 4. Проверка и преобразование текста

| Команда | Действие |
| --- | --- |
| `isdigit` | Проверка, состоит ли строка только из цифр |
| `isalpha` | Проверка, состоит ли строка только из букв |
| `strip` | Удаление пробелов в начале и в конце строки |
| `format` | Вывод числа с двумя знаками после точки |
| `r` | Разворот строки срезом `[::-1]` |
| `l` | Перевод в нижний регистр |
| `f` | Перевод в верхний регистр |

### Уровень 5. Цепочка методов

На этом уровне показан последовательный вызов методов на заранее заданной строке:

```python
'    pYtHon;is;AWESome    '.strip().replace(';', ' ').upper().capitalize()
```

Сначала удаляются пробелы по краям, точки с запятой заменяются пробелами, затем изменяется регистр. Результат:

```text
Python is awesome
```

**Результат работы:** интерактивный тренажёр с пятью уровнями, пояснениями и возможностью применять строковые операции к своему тексту. Отдельной команды завершения программы нет.

## Домашняя работа № 3. Консольная игра «Лабиринт»

**Цель:** объединить функции, циклы, списки, словари и случайные события в одной игровой программе.

Игрок исследует поле размером **5 × 5**, решает примеры, собирает предметы и ищет ключ. Чтобы победить, нужно дойти до правой нижней комнаты с ключом в инвентаре.

### Генерация поля

Функция `generate_maze()` создаёт двумерный список комнат. Каждая комната — это словарь с типом и признаком посещения. Типы обычных комнат выбираются случайно: пустая комната, задача, ловушка, сундук или портал. После этого задаются старт в левом верхнем углу, выход в правом нижнем и одна комната с ключом.

### Карта и передвижение

Функция `show_map()` показывает положение игрока и уже исследованные комнаты. Неизвестные клетки скрыты знаком `❓`.

| Символ | Значение |
| --- | --- |
| `🧍` | Текущее положение игрока |
| `❓` | Неисследованная комната |
| `⬜️` | Пустая комната |
| `🧮` | Задача |
| `⚠️` | Ловушка |
| `📦` | Сундук |
| `🌀` | Портал |
| `🔑` | Ключ |
| `🏁` | Старт |
| `🚪` | Выход |

Передвижение выполняется командами `w`, `a`, `s`, `d`. Программа не позволяет выйти за край поля.

### Задачи и предметы

Функция `generate_problem()` составляет пример на сложение, вычитание или умножение. Для вычитания числа меняются местами, чтобы результат не был отрицательным. Если в инвентаре есть калькулятор, его можно использовать как подсказку.

За правильный ответ игрок получает случайный предмет: зелье, калькулятор, подсказку или щит. За ошибку снимаются очки здоровья. Щит уменьшает полученный урон вдвое.

В комнате с ключом нужно решить более сложный пример. Ловушка тоже задаёт пример, но без награды. В сундуке находятся один или два предмета. Портал переносит игрока в случайную комнату.

### Инвентарь

По команде `i` открывается меню инвентаря: предметы можно отсортировать, выбросить или выпить зелье. Зелье восстанавливает 30 единиц здоровья, но не больше 100.

Управление: `w/a/s/d` — движение, `i` — инвентарь, `q` — выход из игры. Если здоровье падает до нуля, игра заканчивается проигрышем.

**Результат работы:** законченная консольная игра с генерацией поля, боевой системой на примерах, инвентарём и условием победы.

## Домашняя работа № 5. Калькулятор стоимости занятий репетитора

**Цель:** сделать одно и то же простое приложение на двух графических библиотеках — **Tkinter** и **Qt (PySide6)** — и сравнить, как в них устроены окно, поля ввода и обработка нажатий.

Я написал калькулятор стоимости занятий репетитора. Он считает сумму за несколько занятий с учётом типа часа (академический 45 минут или астрономический 60 минут), скидки, выезда и уже внесённой оплаты.

Общая математика вынесена в модуль `homework5/logic.py`, который не зависит от графических библиотек. Окна только собирают ввод, вызывают этот модуль и показывают результат.

| Файл | Назначение |
| --- | --- |
| `logic.py` | Проверка ввода и расчёт стоимости |
| `app_tkinter.py` | Окно на Tkinter |
| `app_qt.py` | Окно на Qt (PySide6) |
| `requirements.txt` | Зависимость `PySide6` для версии на Qt |

### Как считается стоимость

1. Сначала считается стоимость занятий: ставка за час умножается на число часов в одном занятии и на количество занятий.
2. Скидка применяется только к этой сумме.
3. Плата за выезд добавляется целиком, без скидки.
4. Если указано, сколько уже оплачено, программа показывает долг, сдачу или полный расчёт.
5. Дополнительно выводится общее время занятий.

Пример: ставка **1500** руб. за академический час, **2** часа, **8** занятий, скидка **10 %**. Стоимость без скидки — **24 000** руб., скидка — **2400** руб., к оплате — **21 600** руб., всего времени — **12 ч 00 мин**. Если уже внесено **10 000** руб., останется доплатить **11 600** руб.

### Проверка ввода

Ставка, число часов и количество занятий должны быть больше нуля. Количество занятий — целое число. Скидка — от 0 до 100, выезд и оплата — не меньше нуля. Пустые поля скидки, выезда и оплаты считаются нулями. Можно писать десятичную запятую, например `1,5`.

Если поле заполнено неверно, программа очищает предыдущий результат, показывает диалог «Ошибка ввода» и возвращает курсор в это поле.

### Чем похожи и чем отличаются две версии

Обе версии выглядят одинаково: те же подписи, те же поля, та же кнопка **«Рассчитать»**, тот же текст результата. Расчёт в обоих случаях выполняет функция `calculate_from_forms()` из `logic.py`. Запустить расчёт можно кнопкой или клавишей Enter.

Отличается способ, которым библиотеки собирают окно и реагируют на действия пользователя.

| | Tkinter | Qt (PySide6) |
| --- | --- | --- |
| Окно | Класс наследуется от `tk.Tk` | Главное окно — `QMainWindow`, внутри него виджет-контейнер |
| Виджеты | `ttk.Label`, `ttk.Entry`, `ttk.Combobox`, `ttk.Button` | `QLabel`, `QLineEdit`, `QComboBox`, `QPushButton` |
| Компоновка | `grid()`: подписи в левом столбце, поля в правом | `QFormLayout` для подписей и полей, `QVBoxLayout` для заголовка, формы, кнопки и результата |
| Действие кнопки | В `command=` передаётся обычная функция-колбэк | Сигнал `clicked` соединяется со слотом `calculate()` через `clicked.connect(...)` |
| Клавиша Enter | Привязка события: `bind("<Return>", ...)` | Сигнал `returnPressed` у каждого поля ввода |
| Сообщение об ошибке | `tkinter.messagebox.showwarning()` | `QMessageBox.warning()` |

В Qt используется схема «сигнал — слот»: виджет сам сообщает, что произошло событие, а метод окна на него подписывается. В Tkinter обработчик указывается сразу при создании кнопки или привязывается к событию строкой вида `<Return>`.

## Домашняя работа № 6. Графический интерфейс с базами данных SQLite и PostgreSQL

**Цель:** подключить к одному графическому приложению две системы управления базами данных — локальную **SQLite** и промышленную **PostgreSQL** — и разобрать работу с таблицами, ограничениями и SQL-запросами.

В задании нужно было «привязать к одной из ГУИ две БД + СУБД». Я сделал оконное приложение «Магазин» на `tkinter`: в нём можно вести список покупателей и их заказов, переключаться между SQLite и PostgreSQL и выполнять типичные операции с базой.

Файл программы: `homework6/app.py`.

### Как работает приложение

1. В верхней панели выбирается СУБД. Для SQLite достаточно нажать **«Подключиться»** — рядом со скриптом создаётся файл `shop.db`. Для PostgreSQL нужно указать хост, порт, имя базы, пользователя и пароль (по умолчанию `localhost`, `5432`, `postgres`, `postgres`, пароль пустой).
2. При успешном подключении приложение само создаёт таблицы, если их ещё нет.
3. В форме **«Добавить покупателя»** вводятся имя и email. Email должен быть уникальным.
4. В форме **«Добавить заказ»** покупатель выбирается из списка, затем указываются товар и количество. Количество должно быть больше нуля.
5. На вкладке **«Покупатели»** отображается таблица клиентов, на вкладке **«Заказы»** — заказы вместе с именем покупателя. Имя берётся из связанной таблицы через `JOIN`.
6. Поле **«Поиск по покупателю»** фильтрует обе таблицы запросом `SELECT ... WHERE ... LIKE`.
7. Кнопка **«Удалить выбранную запись»** удаляет строку из текущей вкладки. Покупателя с заказами удалить нельзя, пока не удалены связанные заказы: срабатывает внешний ключ.

### Подключение к базам данных

| СУБД | Как подключается приложение |
| --- | --- |
| **SQLite** | Модуль `sqlite3` входит в Python. Это локальная СУБД: вся база хранится в одном файле. После подключения выполняется `PRAGMA foreign_keys = ON`, иначе SQLite не проверяет внешние ключи. |
| **PostgreSQL** | Используется драйвер `psycopg2`. Он импортируется только при выборе PostgreSQL, поэтому приложение запускается и без этой библиотеки, если нужна только SQLite. |

Обе СУБД работают через один класс `Database` с общим интерфейсом. Отличаются только детали: в SQLite плейсхолдер параметров — `?`, в PostgreSQL — `%s`; автоинкремент задаётся как `INTEGER PRIMARY KEY AUTOINCREMENT` или как `SERIAL PRIMARY KEY`.

Цикл работы с базой один и тот же:

1. `connect()` — открыть соединение;
2. `cursor()` — получить курсор;
3. `execute()` — выполнить SQL-запрос;
4. `commit()` / `rollback()` — сохранить изменения или отменить их при ошибке;
5. `close()` — закрыть соединение при выходе из программы.

### Структура таблиц

Схема совпадает с примером из лекции. Покупатели и заказы связаны через первичный и внешний ключ.

```sql
CREATE TABLE customers (
    id INTEGER PRIMARY KEY,          -- в PostgreSQL: SERIAL PRIMARY KEY
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL
);

CREATE TABLE orders (
    id INTEGER PRIMARY KEY,          -- в PostgreSQL: SERIAL PRIMARY KEY
    customer_id INTEGER NOT NULL,
    product TEXT NOT NULL,
    quan INTEGER NOT NULL CHECK (quan > 0),
    FOREIGN KEY (customer_id) REFERENCES customers(id)
);
```

- `id` в обеих таблицах — **первичный ключ (PK)**. Он уникально обозначает запись.
- `orders.customer_id` — **внешний ключ (FK)**. Он ссылается на `customers.id` и связывает заказ с покупателем.
- Связь **«один ко многим»**: у одного покупателя может быть несколько заказов, а каждый заказ принадлежит только одному покупателю.
- `NOT NULL` не позволяет оставлять обязательные поля пустыми.
- `UNIQUE` запрещает повторять один и тот же email.
- `CHECK (quan > 0)` не даёт сохранить заказ с нулевым или отрицательным количеством.

Если попытаться добавить второй одинаковый email, заказ без покупателя или удалить клиента, у которого ещё есть заказы, база вернёт ошибку, а программа покажет её в диалоговом окне.

### Какие SQL-запросы используются

- `CREATE TABLE IF NOT EXISTS` создаёт таблицы при первом подключении.
- `INSERT INTO customers (name, email) VALUES (?, ?)` добавляет покупателя.
- `INSERT INTO orders (customer_id, product, quan) VALUES (?, ?, ?)` добавляет заказ.
- `SELECT ... FROM ... WHERE name LIKE ? OR email LIKE ?` ищет покупателя.
- `JOIN` соединяет заказы с покупателями, чтобы в таблице было видно имя клиента.
- `DELETE FROM ... WHERE id = ?` удаляет выбранную запись.

Пример запроса для вкладки «Заказы»:

```sql
SELECT o.id, c.name, o.product, o.quan
FROM orders AS o
JOIN customers AS c ON c.id = o.customer_id
WHERE c.name LIKE ? OR c.email LIKE ?
ORDER BY o.id;
```

Значения в запросы передаются как параметры, а не склейкой строк. Так безопаснее, и один и тот же код подходит и для SQLite, и для PostgreSQL: плейсхолдер просто заменяется на `?` или `%s`.

Нужен Python 3 с модулем `tkinter` (обычно он уже установлен). Для работы с PostgreSQL дополнительно ставится драйвер:


Файл `requirements.txt` содержит пакет `psycopg2-binary`. Если нужен только SQLite, приложение можно запускать и без этой установки.

Для PostgreSQL на компьютере должен быть запущен сервер. В поля подключения подставляются адрес, порт, имя базы, пользователь и пароль.

### Как проверить результат

1. Выбрать **SQLite** и нажать **«Подключиться»**. В строке состояния должен появиться путь к файлу `shop.db`.
2. Добавить покупателя, например `Иван Иванов` с email `ivan@mail.test`. Запись должна появиться на вкладке «Покупатели».
3. Попытаться добавить второго покупателя с тем же email. Программа должна показать ошибку нарушения `UNIQUE`.
4. Выбрать этого покупателя, добавить заказ «Тетрадь» в количестве `3`. Запись должна появиться на вкладке «Заказы» с именем покупателя.
